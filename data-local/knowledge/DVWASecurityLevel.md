# 页面即情报：网页自带线索先读懂再动手（DVWA Security Level 页为例）

## 思维方式
http_fetch / web_crawl 拿到的页面不只是测试对象——**页面内容本身就是情报**。每次拿到新页面，先扫一遍文本线索，再决定测试动作。

## 高价值线索类型
- **配置/说明页**：如 DVWA /security.php——页面明示当前安全等级（Security level is currently: X）、四个等级的含义与调整入口（low 完全无防护做漏洞演示 / impossible 是安全实现对照），甚至标注版本沿革（v1.9 中 impossible 曾名为 high）
- **HTML 注释**：TODO 备注、隐藏逻辑、开发调试信息
- **hidden input**：CSRF token、内部参数、引用的接口路径
- **页脚/关于/帮助页**：框架指纹与版本号（直接关联历史漏洞检索）
- **报错信息**：堆栈、SQL 错误、物理路径泄露
- **setup / readme / 文档页**：默认凭据、未删除的安装指引

## 实战示例（DVWA）
模块测试全部无效时，先访问 /security.php 读当前等级：
- 显示 impossible/high → 按「DVWA 安全等级调整」条目降级到 low 演示漏洞链，再逐级升回验证绕过
- 页面文字本身已给出各等级定位，无需猜测

## 行动建议
1. 新页面到手先做一次"线索扫描"（配置项/注释/版本/报错），再执行测试
2. 发现可操作配置（安全等级/功能开关/参数）时评估利用价值
3. 具备通用价值的页面知识用 knowledge_save 沉淀，供后续任务复用
