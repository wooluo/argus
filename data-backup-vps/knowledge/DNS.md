# DNS 泛解析目标的子域名枚举：假资产识别与过滤

## 适用场景
目标域名开启了 DNS 泛解析（wildcard DNS）——任意编造的不存在子域名都会解析到同一 IP。特征：枚举结果数千条、大量同构命名（mail001~999、web0001~9999）、http_alive 探测后统一跳转同一错误页。

## 判定方法
随机编造 4 个三级域名（如 xxxxrandom1234.domain.com）解析：若 ≥3 个返回 IP → 泛解析开启，其 IP 集合即「泛解析 IP」。

## 平台行为
subfinder / osint ct_logs 已内置过滤（core/dns_utils）：解析完全落在泛解析 IP 的枚举结果自动剔除（假资产不入库），结果带 wildcard/wild_count 标记。看到该标记说明剩余子域名是真实独立解析。

## Agent 注意事项
1. 假资产不要浪费步数探测——对泛解析 IP 的 http 请求只会得到统一错误页
2. 保留的子域名解析到不同 IP，是真实独立服务，值得逐个验证
3. 同一主机多个路径返回相同响应体（http_fetch 已带响应折叠提示）时，路径枚举无效，转向参数化接口
4. 判断子域名真假：解析 IP 是否落在泛解析 IP 集合内
